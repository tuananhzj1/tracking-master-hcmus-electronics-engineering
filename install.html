Bước 2: Sử dụng

  1. Đăng nhập student.hcmus.edu.vn
  2. Mở trang Kết quả học tập → nhấn bookmark HCMUS Tracker
  3. Mở trang Đăng ký học phần → nhấn bookmark lần nữa
  4. Xong! Hộp tracker hiện ra ở góc phải màn hình 🎉

❓ Kéo không được?

Nếu trình duyệt chặn kéo-thả, làm theo cách thủ công:
1. Mở file master-tracking-hcmus trên GitHub
2. Nhấn nút Raw → Ctrl+A → Ctrl+C
3. Chuột phải thanh bookmark → Thêm trang
4. Tên: HCMUS Tracker — URL: dán nội dung vừa copy
5. Nhấn Lưu
⚠️ Chrome/Edge có thể tự xóa tiền tố javascript: khi dán. Nếu bị, hãy gõ tay javascript: trước rồi dán phần còn lại.
